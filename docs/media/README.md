# Clips for `docs/presentation.html`

Drop your own screen recordings here. Each file replaces the diagram of its scene; scenes without a file keep the diagram.

| File | Scene | What to record | Length |
|---|---|---|---|
| `scene2.mp4` | She lives on your desktop | Her resting on the taskbar, then switching "When she rests" from left to right in her menu | 8 s |
| `scene3.mp4` | Talk to her | Say "Capri" + an order ("abre mi música"): the listening pill, then her card | 9 s |
| `scene4.mp4` | Dictation | Hold Ctrl+Alt+Space in Notepad, say a sentence, let go: the text appears | 8 s |
| `scene5.mp4` | Messages, quietly | A message arriving as her card with the sound, and writing a reply from it. Use a test chat, no real names | 8 s |
| `scene6.mp4` | Light on your PC | `ollama ps` / Task Manager memory with the big model leaving, or her model menu | 8 s |
| `scene7.mp4` | Safe by default | An Allow / Deny card ("instala qwen3:8b") and a Downloads scan card | 7 s |

Tips: MP4 (H.264) or WebM, no sound, 16:9 (crop to the part of the screen that matters), 30 fps, 1280x720 is plenty, each under ~8 MB. A `.gif` with the same name also works. Hide anything private first: contacts, file names, notifications.
